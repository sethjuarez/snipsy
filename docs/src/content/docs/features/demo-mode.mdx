Demo mode is where Snipsy shines — it activates all your configured hotkeys as **system-wide shortcuts**, so they work no matter which application is focused.

## Entering Demo Mode

Check the **Demo preflight** card on the Overview first. It shows how many hotkeys will be armed and flags duplicate or invalid hotkeys, snippets or clips without a hotkey, clips missing a source video, and (on Windows) missing admin rights.

Then click **Start demo** in the title bar or the preflight card (or press **Ctrl/Cmd+K** and run "Start demo"). The first time, and whenever no hotkeys would be armed, Snipsy explains what will happen before starting. Snipsy will:

1. Register eligible snippet, clip, and automation hotkeys as global shortcuts (the first item using a hotkey wins)
2. Minimize the app to the **system tray** (menu bar on macOS)
3. Switch the tray icon to a bright green indicator

Your audience never sees Snipsy — they just see text appearing and videos playing as if by magic.

## During Demo Mode

- Press any configured hotkey to trigger its snippet
- **Text snippets** deliver to the currently focused window
- **Video clips** open as fullscreen overlays (press **Escape** to dismiss early)
- Snipsy is invisible — only the tray icon shows it's active

## Video Clips During Demo Mode

When a video clip reaches a pause stop, playback holds on that frame so you can narrate. If the stop has a spotlight, Snipsy highlights the configured region after the paused frame is ready.

Use these controls while the video overlay is active:

| Key | Action |
|-----|--------|
| **Space** or **Click** | Resume from the current pause stop |
| **Right Arrow** | Jump to the next playback stop |
| **Left Arrow** | Jump to the previous playback stop |
| **Escape** | Close the video overlay |

Playback stops are the clip start, each pause stop, and the clip end. If the clip has no pause stops, the arrow keys jump between start and end.

## Exiting Demo Mode

Three ways to exit:

1. **Right-click the tray icon** → "Exit Demo Mode"
2. **Click the tray icon** to show Snipsy, then click **Stop demo** in the title bar or on the Overview
3. The `exit-demo-mode` event from the tray menu

All global hotkeys are unregistered and the tray icon returns to its idle (purple) state.

<Aside type="tip">
Practice your demo flow before going live! Enter demo mode and run through all your hotkeys to make sure the order feels natural.
</Aside>

## Hotkey Conflicts

If a hotkey conflicts with another application's shortcut, Snipsy includes a **low-level keyboard hook fallback** on Windows that can intercept keys even when the standard global shortcut registration fails.

<Aside type="caution">
Some security software may flag low-level keyboard hooks. If your hotkeys aren't working, check that Snipsy is allowed through your security settings.
</Aside>
