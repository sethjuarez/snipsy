Automations prepare the machine before or during a demo. Today an automation opens sites in your default browser, so one key press can put every tab you need in place.

<Aside type="caution" title="Experimental Feature">
Automations are an Advanced-mode feature and still evolving. Open site is the only action kind for now.
</Aside>

## Steps and actions

An automation is a list of **steps**, and each step holds **actions**. Snipsy runs the steps top to bottom, and the actions inside each step top to bottom. What you see in the editor is the order they run in. Each action shows its position, such as `2.1` for the first action in step 2.

| Action | What it does |
|--------|--------------|
| **Open site** | Opens an `http://` or `https://` URL in the default browser. If the same URL appears more than once in an automation, it only opens the first time. |

## Creating an automation

Open **Automations** and click **Add**. Give it a name, and if you like, a hotkey so it runs during demo mode. Then:

1. Click **+ Add step** and name the step.
2. Click **+ Add action** on the step and fill in the URL. The URL field gets focus, so you can start typing right away.
3. Click **Create** (**Update** when editing) or press **Ctrl/Cmd+S** to save.

## Reordering steps and actions

You can change the order without retyping anything. Every move keeps the action's settings as they are.

- **Move up / Move down** arrows on an action move it one place within its step. The arrows on a step header move the whole step.
- **+** on an action inserts a new Open site action right below it.
- **Drag** the grip handle to the left of an action to drop it anywhere, including in another step. Drag the handle on a step header to move the step and all its actions. An empty step shows a drop area you can drag actions into.
- **Keyboard**: focus a grip handle, press **Space** to pick it up, use the **arrow keys** to move it, then press **Space** to drop it or **Esc** to cancel.

Reordering counts as an unsaved change. Moving something back where it started clears the change.

## Running an automation

Run an automation with **Run** on its row in the list, with its hotkey during demo mode, or from a Stream Deck key. Automations are saved as JSON files in the project's `automations/` folder.
