Text snippets are the core of Snipsy — pre-loaded text that gets delivered to the active window when you press a hotkey.

<Screenshot src="/images/text-list.png" alt="Text snippet list" caption="The text snippets list showing all configured snippets" />

## Creating a Snippet

Click the **+** button in the Snippets view header. Fill in:

| Field | Description |
|-------|-------------|
| **Title** | A short label for the snippet |
| **Description** | Optional notes for yourself |
| **Hotkey** | Click the capture field and press your shortcut |
| **Text** | The content to deliver |
| **Delivery** | `fast-type` or `paste` (see below) |
| **Type Delay** | Milliseconds between keystrokes (fast-type only) |
| **Typos** | Chance (0–20%) a letter or digit is mistyped, then fixed (fast-type only) |
| **Rhythm Variation** | How much (0–100%) key timing drifts (fast-type only) |

## Delivery Modes

### Fast-Type

Simulates individual keystrokes as if you're typing. This looks natural to your audience — they see text appearing character by character.

- **Type Delay** controls speed (default: 30ms between keys)
- Works with any application that accepts keyboard input
- Best for: code demos, terminal commands, live coding

#### Humanize

Two optional settings make fast-type look less robotic. Both are re-randomized on every run, and the final text always matches the snippet.

| Setting | Effect |
|---------|--------|
| **Typos** | Mistypes a letter or digit (nearby key, doubled, swapped, or skipped), pauses as if noticing, then fixes it with Backspace. Mistakes never span a space, symbol, or line break. |
| **Rhythm Variation** | Uneven key timing, with short pauses after spaces and line breaks. |

<Aside type="caution">
Turn **Typos** off for fields that react to each keystroke, like browser address bars and spreadsheet cells with inline autocomplete, or masked inputs. A mistyped key can accept a suggestion that Backspace doesn't undo.
</Aside>

#### Images

Fast-type snippets can paste images mid-text. Add a reference like `{{image:logo.png}}` where the image should appear; Snipsy types the text before it, pastes the image from the clipboard, then keeps typing. Images are never humanized.

| Where | How |
|-------|-----|
| **Snippets → Images** tab | **Import Image** (PNG or JPEG), **Copy reference**, or delete. Each row shows how many snippets use it. |
| Snippet editor | **Insert image** picks an existing image; **Import image…** adds a file; pasting an image into the text adds it too. |

Images are copied into the project's `images/` folder, so they travel with exports. The editor and pre-demo checklist flag malformed references, missing images, and snippets set to **Paste** (paste delivery can't include images).

<Aside type="tip">
The target app must accept pasted images (e.g. Word, Teams, Slack, Paint). Plain-text editors ignore them.
</Aside>

### Paste

Inserts the full text via the clipboard (`Ctrl+V`). Instant delivery — the entire text appears at once.

- Fastest delivery method
- Best for: large blocks of text, URLs, configuration snippets

<Aside type="tip">
Use **fast-type** for lines your audience should watch being "typed" (like code), and **paste** for boilerplate they don't need to see character by character.
</Aside>

## Hotkey Format

Hotkeys use the Tauri accelerator format:

- `CmdOrControl+Shift+1` — works as Cmd on macOS, Ctrl on Windows/Linux
- `Alt+Shift+A` — modifier combinations
- Single keys like `F5` are also supported

The hotkey capture widget records exactly what you press — no need to memorize the format.

<Aside type="caution">
Avoid hotkeys that conflict with the application you're demoing. Common safe choices are `Ctrl+Shift+[number]` combinations.
</Aside>
