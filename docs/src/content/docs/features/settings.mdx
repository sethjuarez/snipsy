Open **Settings** with the gear in the title bar, **Ctrl/Cmd+,**, or **Settings** in the command palette. It works with or without a project open. Search filters the sections.

| Section | What it does |
| --- | --- |
| **Appearance** | Theme: **System** (follows the OS), **Light**, or **Dark**. The title-bar sun/moon toggles light and dark. |
| **Demo** | Turns the checklist shown before starting a demo on or off. Snipsy always asks when no hotkeys would be armed. |
| **Permissions** | Windows only. Shows whether Snipsy runs as administrator and offers **Restart as administrator**. Admin rights let Snipsy block your keyboard and mouse while it types and type into elevated apps. |
| **Updates** | Shows the version, checks for updates, and installs one when available. |
| **Stream Deck** | Explains the plugin and opens the key preview. |
| **Shortcuts** | Lists in-app shortcuts and opens the [Hotkeys view](/features/hotkey-overview/#hotkeys-view). |

The shield in the title bar, shown when Snipsy isn't elevated, opens **Permissions** directly.
