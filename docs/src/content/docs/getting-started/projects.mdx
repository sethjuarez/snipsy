## What is a Project?

A Snipsy project is a **folder on disk** containing all your demo assets: text snippets, video clips, scripts, and configuration. Everything is stored as plain JSON files, so projects are easy to version control and share.

## Folder Structure

```
my-demo-project/
├── project.json           # Project metadata + all snippets
├── scripts/               # Automation scripts (JSON)
│   └── build-demo.json
├── images/                # Images embedded in text snippets ({{image:key}})
│   └── logo.png
└── videos/                # Imported video files
    ├── build-process.mp4
    └── deploy-demo.mp4
```

## project.json

The main project file contains:

```json
{
  "name": "My Demo",
  "description": "A demo for the conference talk",
  "textSnippets": [
    {
      "id": "uuid-here",
      "title": "React Import",
      "text": "import React from 'react';",
      "hotkey": "CmdOrControl+Shift+1",
      "delivery": "fast-type",
      "typeDelay": 30
    }
  ],
  "videoSnippets": [
    {
      "id": "uuid-here",
      "title": "Build Process",
      "videoFile": "videos/build-process.mp4",
      "startTime": 0,
      "endTime": 30,
      "hotkey": "CmdOrControl+Shift+4",
      "speed": 2,
      "muted": true
    }
  ]
}
```

## Recent Projects

Snipsy remembers your recently opened projects. They appear on the welcome screen for quick access. Click a recent project to open it, or use the **×** button to remove it from the list.

<Aside type="tip">
Since projects are just folders with JSON files, you can store them in Git, OneDrive, or any sync service to share demo setups across machines.
</Aside>

## Opening Existing Projects

Click **Open Project** on the welcome screen and select the folder containing `project.json`. Snipsy detects the project file and loads everything automatically.

## Export and Import

Move a project to another machine or hand it to a colleague as a single file.

| Action | Where | What happens |
|--------|-------|--------------|
| **Export project** | Sidebar footer, or the command palette | Saves the whole folder, videos included, as a `.snipsy.zip`. `.git` is skipped. |
| **Import Project** | Welcome screen | Pick a `.zip`, then an empty folder. Snipsy unzips it there and opens it. |

<Aside type="note">
Export saves what's on disk. Save any open editor first; Snipsy warns you if unsaved changes were left out.
</Aside>

## Getting Around

The sidebar groups a project by what you do with it:

| Group | Views | Use it to |
|-------|-------|-----------|
| — | **Overview** | Check demo readiness and arrange your run sheet |
| Content | **Snippets**, **Clips** | Build what you present. Clips has a **Source videos** tab for the recordings clips are cut from. |
| Setup | **Automations** | Prepare the machine before or during a demo |
| Controls | **Hotkeys**, **Stream Deck** | Review and fire everything you can trigger |

**Ctrl/Cmd+1–6** jump to each view in order.
## Finding Items

The Text, Clips, and Automations lists each have a filter box. Type part of a name, description, hotkey, or content (clip file, automation URL) to narrow the list. Press **Esc** to clear it. Drag-to-reorder is paused while a filter is active.
