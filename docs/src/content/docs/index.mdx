## What is Snipsy?

Snipsy is a desktop application built for **live demo presenters**. It lets you pre-load text snippets and video clips, assign global hotkeys, and trigger them instantly during a presentation — no Alt-Tabbing, no copy-pasting, no awkward pauses.

<CardGrid>
  <Card title="Text Snippets" icon="pencil">
    Pre-load code, commands, or any text. Trigger via hotkey to fast-type or paste into the active window.
  </Card>
  <Card title="Video Clips" icon="laptop">
    Import videos, trim to specific ranges, and play fullscreen overlays at custom speeds.
  </Card>
  <Card title="Global Hotkeys" icon="rocket">
    Assign keyboard shortcuts that work system-wide — even when Snipsy is hidden.
  </Card>
  <Card title="Demo Mode" icon="star">
    Enter demo mode to activate all hotkeys. Snipsy minimizes to the system tray so your audience never sees it.
  </Card>
</CardGrid>

## Key Features

- **Fast-type or paste** delivery for text snippets
- **Fullscreen video playback** with speed control, mute, and click-to-play
- **Multi-monitor support** — target any display for video playback
- **Drag-and-drop hotkey overview** dashboard
- **System tray** integration with demo mode indicator
- **Auto-updater** built in
- **JSON-based projects** — version control your demo setups
